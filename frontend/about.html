About Smart Voice Generator

Smart Voice Generator is a web-based Text-to-Speech application developed for Text and Speech Analysis. It converts written text into spoken output while providing text statistics and customizable speech controls.

Project objective

The project shows how written language can be analyzed and turned into speech inside an ordinary web page. A user enters text, sees measurements such as word count and speaking time, chooses a voice, adjusts how it sounds, and listens to the result. Each request is saved so it can be reused later.

Key features

  • Text editor with live character, word and sentence counters and a 5,000 character limit
  • Voice and language selection from the voices installed on your device
  • Speed, pitch and volume controls with play, pause, resume and stop
  • Voice preview with a short sample sentence
  • Speech history stored in SQLite, with reuse and delete actions
  • Light and dark themes, saved settings, and a layout that adapts to phones and tablets

Technology stack

  • Frontend: HTML5, CSS3 and vanilla JavaScript
  • Speech: the browser's Web Speech API (SpeechSynthesis)
  • Backend: Python with Flask, exposing a REST API
  • Database: SQLite, queried with parameterized statements

Text analysis

Statistics are calculated in the browser every time the text changes: characters with and without spaces, words, sentences, paragraphs, average words per sentence, estimated reading time (200 words per minute) and estimated speaking time (150 words per minute, adjusted by the speed setting). Sentences end at a full stop, question mark, exclamation mark, ellipsis or the Devanagari danda, so Hindi text is counted correctly. The server offers the same calculation at POST /api/analyze.

Speech synthesis

Speech is generated by the speech engine built into your browser and operating system. The app splits long text into sentences and speaks them in order, which keeps playback reliable in browsers that cut off long utterances. Speed, pitch and volume are read before each sentence, so changes take effect as you move the sliders.

Browsers do not let a web page record this output, so audio download is not offered with browser voices. The static/audio/ folder is reserved for files created by a server-side speech engine, if one is added later.

Browser compatibility

Speech synthesis works in current versions of Chrome, Edge, Safari and Firefox. The list of languages and voices depends on the browser and the operating system, so a Tamil, Hindi, Telugu, Malayalam or Kannada voice appears only if your device provides one. Some browsers load voices a moment after the page opens, and some mobile browsers do not support pausing. If no voices are found, the app tells you instead of failing silently.

Smart Voice Generator is a Text and Speech Analysis subject project. Speech is produced by your browser, so voices differ between devices.
